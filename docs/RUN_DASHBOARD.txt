COFFEE MARKET DASHBOARD - QUICK START

1. Extract the project completely.
2. Open the extracted project folder.
3. Open the dashboard folder.
4. Double-click START_DASHBOARD.cmd (or run_dashboard.bat).
5. The launcher starts Streamlit and opens the dashboard in your browser.

From the project root, you can also run:
    streamlit run dashboard\app.py

IMPORTANT:
Do NOT run:
    python dashboard\app.py

The dashboard must be launched through Streamlit.
