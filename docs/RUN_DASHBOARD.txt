COFFEE MARKET DASHBOARD - QUICK START

1. Extract the ZIP completely.
2. Open the extracted project folder.
3. Double-click START_DASHBOARD.cmd (or run_dashboard.bat).
4. The launcher starts Streamlit correctly and opens the dashboard in your browser.

IMPORTANT:
Do NOT double-click dashboard\app.py and do NOT run it with:
    python dashboard\app.py

The dashboard must be launched through Streamlit.
