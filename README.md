# BrewInsights — Indian Coffee Market Intelligence

> End-to-end Indian coffee consumer analytics, customer segmentation, machine learning, demand analysis, and interactive dashboard.

This repository is being populated with the structured BrewInsights project package.

## Project workflow

`Raw Survey Data` → `Cleaning & Preprocessing` → `EDA` → `Customer Segmentation` → `Predictive Modeling` → `Market & City Intelligence` → `Interactive Dashboard`

## Contents

- `notebooks/` — analysis notebook
- `dashboard/` — interactive dashboard application
- `data/` — raw and derived datasets
- `outputs/` — model, segmentation, and market-intelligence outputs
- `docs/` — project documentation
- `scripts/` — supporting scripts

## Core stack

Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Streamlit · Jupyter

See the project package for the full interactive README and supporting artifacts.
