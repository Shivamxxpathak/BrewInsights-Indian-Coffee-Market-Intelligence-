# Data

This folder separates source survey data from cleaned/derived analytical data.

- `raw/` — original survey export supplied for the project.
- `processed/` — cleaned dataset used by the analysis workflow.
- `external_city_data.csv` — city-level supporting features used by the market-entry analysis.
- `coffee_demand_*.csv` — demand trend, forecast, and model-comparison outputs used by the dashboard.
- `modules/` — supporting city-score data.

The repository preserves the project's existing analytical outputs; it does not silently replace model results or invent additional observations.
